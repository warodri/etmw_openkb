Agent mode

Use OpenKB from opencode, the coding agent, with the local model. No desktop app needed.

What it is

opencode talks to OpenKB through a small read-only bridge (an MCP server). Ask opencode a factual question and it calls the library, then repeats the sources it got back. It can't write to the library, edit files or run shell commands in this mode.

Its own allowance

The bridge has its own daily quota, separate from the web app's. Agents can never use up what the people at the keyboard get. Default: 100 tool calls per UTC day, set with OPENKB_AGENT_DAILY_CAP. When it's spent, the bridge says so and waits for the next day.

Start it

  1. Follow Host it yourself. The installer writes opencode.json for you.
  2. Install opencode.
  3. In the OpenKB folder, run opencode.
  4. Pick the openkb agent and ask a question.
Answers only from the library. The agent is told never to answer facts from its own memory.
"Not found" means not found. It says the library doesn't have it and doesn't fill the gap.
Read-only. Edits and shell are denied for this agent.

Full setup details are in the GitHub repo. A desktop app comes later.
