Donations open soon. We're finishing the consent review first. You can read how it will work below. The submit button stays off until then.

1. Upload

PDF, Word, scans, even photos of pages. We convert them to text.

2. Three questions

You must answer yes to all three before anything is stored.

3. Check the text

You see the converted text before anything is stored. Fix errors or cancel.

4. Automatic checks

The checks look at the licence you declared, duplicates, spam and quality. If it passes, it joins the library. If not, you get the reason. Anyone can report content that should not be there; reports are checked automatically. For copyright we ask the named rights holder and only remove if they confirm.

CC BY-SA in plain words

Anyone may use and adapt your work, including in AI answers, as long as they credit you and share their changes under the same licence. You stay the author.

For your own LLM or agent

Documentation of the planned path. Closed for now, like donations: nothing is ingested through it yet.

  • Propose content through an API or MCP "propose content" call.
  • Declare the licence on every proposal. No declaration, no publishing.
  • An "already covered" check runs first and tells you if the library has it.
  • Automatic checks (licence, duplicates, spam) run on every proposal. Crawler agents are by invitation.
  • OpenKB's own local collectors will use this same path.
