Host it yourself

OpenKB runs fully on your own computer: the web app, the local reader, and the library. Nothing here requires a hosted service. This page walks you from zero to answering.

1. What you need

  • Python 3.9 or newer - no packages to install, the server is standard library only.
  • Ollama, running locally.
  • Node.js 20 or newer - only to build the UI; the API works without it.
  • opencode - only if you want agent mode.
  • About 25 GB of free disk for the models.
Disk the models take
qwen3.6:35b-a3b (reader)22.6 GB
qwen3-embedding:4b (embeddings)2.5 GB
app + library index~0.2 GB

Any recent Mac or PC with 16 GB RAM runs it. More RAM helps; the reader is a small model that activates only a slice per token.

3. First run

python3 app/server.py
# UI and API on http://127.0.0.1:8641

Open http://127.0.0.1:8641, ask a question. The first answer can take a minute while the reader model loads; after that it stays warm. Every answer names the documents it used - sources, not truth.

4. How the pieces fit

Everything stays on your machine: the library index, the models, the request log. The web API and the agent bridge share the same server-side guards.

5. Optional: reach it from the internet

Janus (an ETMW product) opens a secure tunnel from your machine to a public address in one command - no router setup, no accounts to juggle.

  1. Install Janus on the machine running OpenKB.
  2. Run janus open openkb:8641.
  3. Share the address it prints.

Optional. OpenKB works fully without it.

6. Troubleshooting

ollama: command not found - install Ollama from ollama.com, start it, then re-run the installer.
model not found - pull the two models: ollama pull qwen3.6:35b-a3b and ollama pull qwen3-embedding:4b.
First answer takes a minute - the reader loads on first use and stays warm while Ollama keeps running.
Port 8641 already in use - run with OPENKB_PORT=8650 python3 app/server.py.
A plain page instead of the app - build the UI once: cd ui && npm install && npm run build.
Ollama on another machine - point at it with OPENKB_OLLAMA_HOST=http://host:11434.
Not enough disk - the models need about 25 GB free; the chart above shows what takes what.
The guards travel with the code: rate limits, the daily cap, the input and answer limits, and the "not in the library" refusal are all server-side - nobody can turn them off from a client. Full details in the GitHub repo.
